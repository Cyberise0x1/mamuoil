# Gold & Platinum Luxury Motion System

The animation system combines three compatible reference principles: Motion Sites’ portfolio-style 3D focal object and animated-background restraint, GSAP’s scoped React timelines with ScrollTrigger and cleanup, and the earlier liquid-glass reference’s use of glass as an information layer rather than decoration.

| Pattern | Mamu Oil application |
| --- | --- |
| 3D focal object | A platinum barrel with liquid oil at the bunghole, a falling droplet, pool ripple, and small splash particles. |
| Professional scrolling | One scoped GSAP context, section-level ScrollTriggers, transform/opacity animation only, and a reduced-motion route. |
| Luxury glass | Gold-edged platinum glass panels with subtle moving sheen and depth, limited to profile, capabilities, and contact data. |
| Route continuity | A gold M-route pulls through the light platinum page, with marker dots responding as sections enter. |

The resulting experience should remain concise: **meaningful motion is reserved for the hero object, section entrances, route flow, and selected capability state**. Routine navigation and input actions remain immediate.
